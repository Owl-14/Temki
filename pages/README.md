# pages/ — HTML-страницы

Каждый файл = одна страница сайта. URL: `/pages/имя.html`

| Файл | Страница |
|------|----------|
| `index.html` | Главная: лента, горячие, квесты |
| `auth.html` | Вход и регистрация |
| `profile.html` | Публичный профиль `@username` |
| `settings.html` | Настройки своего профиля |
| `egg.html` | Страница яйца (вкладки, Q&A, тест) |
| `lay-egg.html` | Создать яйцо + анимация прогрева |
| `edit-egg.html` | Редактирование, вехи, вылупление |
| `chamber.html` | Камера: поиск и фильтры |
| `my-eggs.html` | Кабинет основателя |
| `legend.html` | Легенда мира инкубатора |
| `hall.html` | Зал славы (лидерборды) |
| `activity.html` | Лента событий |
| `notifications.html` | Уведомления |
| `investors.html` | Витрина для кормильцев |

Скрипты страниц лежат в `assets/js/pages/`.  
В корне репо — `index.html` с редиректом сюда (для GitHub Pages).
