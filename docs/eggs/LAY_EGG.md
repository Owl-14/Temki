# Создание яйца (`lay-egg.html`)

Форма «Снести яйцо» и анимация прогрева после сохранения.

## URL

```
/lay-egg.html
```

Только для авторизованных пользователей с заполненным профилем (`username`).

## Поля формы

| Поле | Обязательно | Макс. |
|------|-------------|-------|
| Обложка | нет | webp data URL |
| Название | да | 60 |
| Описание | да | 500 |
| Ссылка | нет | URL |

## Поток после «Положить в инкубатор»

```
Отправка формы
      ↓
Скрыть форму, показать оверлей прогрева
      ↓
createEgg() → Firestore
      ↓
Анимация ~4.2 с (--warm 0 → 1)
      ↓
Редирект на egg.html?id={eggId}
```

При ошибке сохранения оверлей закрывается, форма возвращается.

## Анимация прогрева

Полноэкранный оверлей `#lay-egg-warming`:

| Этап | Визуал | Текст |
|------|--------|-------|
| Старт (`--warm: 0`) | Холодное яйцо: синяя обводка, иней, серый аватар | «Холодное яйцо...» |
| Прогрев | Тепло поднимается снизу, иней тает, оранжевое свечение | «Греем яйцо...» / «Согревается...» |
| Финиш (`--warm: 1`) | Тёплое яйцо в цвете | «Яйцо согрелось!» |

**Картинка внутри яйца:** обложка с формы; если не загружена — плейсхолдер (не аватар профиля).

Прогресс задаётся в JS (`js/lay-egg/warming-animation.js`) через CSS-переменную `--warm` на `.lay-egg-warming__stage` — плавный переход, не зависит от CSS `@keyframes`.

**Свечение и обводка** — на целом `.lay-egg-warming__shell` (одно яйцо, без клипа половинок). При других анимациях яйца не переносить ореол внутрь `overflow: hidden` — см. [ANIMATIONS.md](ANIMATIONS.md), [HATCH.md](HATCH.md).

## Файлы

| Путь | Роль |
|------|------|
| `lay-egg.html` | Форма + разметка оверлея |
| `js/pages/lay-egg.js` | Валидация, `createEgg`, запуск анимации |
| `js/lay-egg/warming-animation.js` | `startLayEggWarming()`, прогресс `--warm` |
| `js/firebase-app.js` | `createEgg()` |
| `style.css` | `.lay-egg-warming__*` |

## После создания

- Запись в `eggs` с `viewCount: 0`, `status: greetsya`
- Запись в `egg_updates`: `type: created`
