# История обновлений яйца

Лента событий жизненного цикла яйца на странице `egg.html`.

## Типы событий

| type | Когда | message (пример) | Статус |
|------|-------|------------------|--------|
| `created` | Создание яйца (`createEgg`) | «Яйцо добавлено в инкубатор» | ✅ |
| `edited` | Сохранение в `edit-egg.html` (`updateEgg`) | «Описание обновлено» | ✅ |
| `status` | Смена статуса | «Статус: цыплёнок» | ⏳ позже |

## Отображение

Вертикальная лента `.egg-page__updates`:

- дата
- текст message

Пусто (старые яйца без записей): «История пока пуста».

## Правила Firestore

```
egg_updates:
  read:  все
  create: только владелец яйца (ownerId совпадает)
  update/delete: false
```

## Запрос

`where eggId == id`, сортировка `createdAt` desc на клиенте.
