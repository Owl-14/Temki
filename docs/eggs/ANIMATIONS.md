# Анимации яйца — общие правила

Прогрев при сносе и вылупление при смене статуса используют одинаковые принципы.

## Две анимации

| Ритуал | Страница | JS | Документ |
|--------|----------|-----|----------|
| Прогрев | `lay-egg.html` | `warming-animation.js` | [LAY_EGG.md](LAY_EGG.md) |
| Вылупление | `edit-egg.html` | `hatch-animation.js` | [HATCH.md](HATCH.md) |

## Общие правила (anti-clipping)

### 1. Форма яйца

- Всегда `border-radius: var(--egg-radius)` (`50% 50% 50% 50% / 58% 58% 42% 42%`).
- Размер оверлея: **200×260 px** (прогрев и вылупление).

### 2. Картинка внутри

- Обложка/аватар в `.…__avatar-wrap` с `inset: 18% 22% 14%`, `object-fit: cover`.
- JS заполняет wrap перед стартом анимации; не хардкодить в HTML.

### 3. Свечение и тени

| Можно | Нельзя |
|-------|--------|
| `box-shadow` / оранжевый ореол на **целом** яйце (`.lay-egg-warming__shell`, `.hatch-overlay__aura`) | `box-shadow` и широкие оранжевые градиенты внутри **клипующих** контейнеров (`overflow: hidden`, половинки 50%) |
| Круглый внутренний `.…__glow` как sibling слоёв скорлупы | Прямоугольная маска половинки как граница для «тепла» |

**Симптом бага:** полупрозрачный **квадрат** или вертикальный срез ореола по центру яйца.

### 4. Разделение скорлупы (только вылупление)

- Половинки `.hatch-overlay__shell--left/right` — только для **клипа аватара** и лёгкого блика.
- Внешнее свечение — на `.hatch-overlay__aura` **вне** половинок.
- Родитель `.hatch-overlay__egg` **без** `overflow: hidden`.

## При добавлении новой анимации

1. Свериться с [LAY_EGG.md](LAY_EGG.md) и [HATCH.md](HATCH.md).
2. Вынести эффекты свечения на слой целого яйца.
3. Проверить с реальной обложкой, не только с градиентным плейсхолдером.
4. Задокументировать слои в соответствующем `docs/eggs/*.md`.
