# Просмотры яйца

## Правило

Считается **только зарегистрированный** пользователь, **только 1 раз** на яйцо.

Наблюдатель открывает страницу — `viewCount` **не растёт**.

**Владелец своего яйца** — просмотр **не засчитывается** ни в статистике яйца, ни в личном тепле, ни в квестах.

## Анти-фарм (обязательно соблюдать в коде)

| Что | Свои яйца | Чужие яйца |
|-----|-----------|------------|
| `eggs.viewCount` | ❌ | ✅ 1 раз на пользователя |
| `egg_views` документ | ❌ | ✅ |
| Личное тепло за просмотр | ❌ | ✅ +1 (первый раз) |
| Тепло яйца за просмотр | ❌ | ✅ +1 (первый раз) |
| Квест «Загляни в 3 яйца» | ❌ | ✅ см. ниже |

Реализация:

- `recordEggView` — выход, если `ownerId === user.uid` (`egg-api.js`)
- `tryRecordView` — не вызывает награды для владельца (`egg-detail.js`)
- Firestore: `egg_views` create только если `eggOwner(eggId) != auth.uid`; `viewCount` bump только если `ownerId != auth.uid`

## Квест «Загляни в 3 яйца»

Прогресс в `localStorage` (`quests.js`), ключ `incubator_quests_{YYYY-MM-DD}`.

**Считаются уникальные яйца за день**, не каждый заход на страницу:

```js
{
  views: 2,              // = viewedEggIds.length
  viewedEggIds: ['id1', 'id2'],
  questions: 0,
  comments: 0,
  claimed: []
}
```

- Функция `trackEggViewQuest(eggId)` — добавляет id в `viewedEggIds`, увеличивает `views` только при **новом** id.
- Повторное открытие того же `egg.html` или F5 **не** увеличивает счётчик.
- **Не** использовать `trackQuestAction('views')` на странице яйца — только `trackEggViewQuest(eggId)`.

### Типичные баги (исправлены)

| Баг | Причина | Правильно |
|-----|---------|-----------|
| 3× F5 на одном яйце = квест выполнен | `views += 1` на каждый визит | Дедуп по `eggId` в `viewedEggIds` |
| Просмотр засчитан при `counted: false` | Квест отвязан от `recordEggView` | Квест только через `trackEggViewQuest`, дедуп внутри |

## Алгоритм

```
Пользователь открыл egg.html?id=
        ↓
  onAuthStateChanged
        ↓
  Не вошёл → показать viewCount как есть
        ↓
  Вошёл → recordEggView(eggId, user, profile)
        ↓
  Транзакция:
    1. egg_views/{eggId}_{uid} существует?
       да → выход, count не меняем
       нет → создать документ + eggs.viewCount += 1
        ↓
  Обновить число на странице
```

## Почему транзакция

Два таба одновременно не должны дать +2. `egg_views` id уникален, `runTransaction` атомарно.

## Правила Firestore

- `egg_views` — create: свой uid, id = `{eggId}_{uid}`, **не владелец яйца**
- `eggs.viewCount` — update +1, если меняется **только** `viewCount` и **`ownerId != auth.uid`**

## UI

Текст: **«N просмотров»** (или «1 просмотр» / «2 просмотра» — склонение опционально).

Старые яйца без поля `viewCount` — показывать `0`.
