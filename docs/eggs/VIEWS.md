# Просмотры яйца

## Правило

Считается **только зарегистрированный** пользователь, **только 1 раз** на яйцо.

Гость открывает страницу — `viewCount` **не растёт**.

## Алгоритм

```
Пользователь открыл egg.html?id=
        ↓
  onAuthStateChanged
        ↓
  Не вошёл → показать viewCount как есть
        ↓
  Вошёл → recordEggView(eggId, user, profile)
        ↓
  Транзакция:
    1. egg_views/{eggId}_{uid} существует?
       да → выход, count не меняем
       нет → создать документ + eggs.viewCount += 1
        ↓
  Обновить число на странице
```

## Почему транзакция

Два таба одновременно не должны дать +2. `egg_views` id уникален, `runTransaction` атомарно.

## Правила Firestore

- `egg_views` — create только свой uid, id = `{eggId}_{uid}`
- `eggs.viewCount` — update +1 любым auth-пользователем, если меняется **только** `viewCount`

## UI

Текст: **«N просмотров»** (или «1 просмотр» / «2 просмотра» — склонение опционально).

Старые яйца без поля `viewCount` — показывать `0`.
