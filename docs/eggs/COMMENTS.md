# Комментарии к яйцу

## Кто может

| Действие | Наблюдатель | Участник |
|----------|-------------|----------|
| Читать | ✅ | ✅ |
| Писать | ❌ | ✅ |
| Ответить | ❌ | ✅ |
| Лайк / дизлайк | ❌ | ✅ |
| Удалять чужие | ❌ | ❌ |

## Форма

- Textarea, max 500 символов
- Кнопка «Отправить»
- Наблюдатель видит: «Погрейся, чтобы комментировать» → `auth.html`

## Ответы

- Кнопка **«Ответить»** под каждым комментарием
- Ответы в **плоском списке** (без сдвига вправо)
- В начале текста ответа: **@username** того, кому отвечают (ссылка на профиль)
- Поле `replyToUsername` в `egg_comments` (или `null` для корневых)
- Старые ответы с `parentId` — @username берётся из родителя при отображении
- Все комментарии: **новые сверху**

## Лайки и дизлайки

- Кнопки 👍 и 👎 под каждым комментарием
- Один голос на пользователя на комментарий
- Повторный клик по активной кнопке — **снимает** голос
- Переключение лайк ↔ дизлайк — одним кликом
- Гости видят счётчики, но кнопки неактивны

Коллекция: `egg_comment_reactions/{commentId}_{uid}`

```js
{
  commentId: string,
  eggId: string,
  uid: string,
  vote: 'like' | 'dislike',
  createdAt: timestamp
}
```

## Отображение

Каждый комментарий:

- `@username` автора (ссылка на профиль)
- displayName
- `@кому_ответ` (если ответ)
- текст
- дата
- 👍 / 👎 / «Ответить»

## API (`js/egg/egg-api.js`)

| Функция | Назначение |
|---------|------------|
| `fetchEggComments(eggId)` | Все комментарии яйца |
| `addEggComment(eggId, profile, text, replyToUsername?)` | Новый комментарий или ответ |
| `fetchEggCommentReactions(eggId)` | Все голоса на яйце |
| `buildReactionStats(reactions, uid)` | Счётчики и голос текущего пользователя |
| `setCommentVote(commentId, eggId, user, vote)` | Лайк / дизлайк / снять |

## Правила Firestore

```
egg_comments:
  read:  все
  create: auth + authorId == uid + text 1..500 + replyToUsername опционально
  delete: только автор
  update: false

egg_comment_reactions:
  read:  все
  create/update/delete: только свой голос (uid)
```

## Тепло и квесты

Комментарий под **чужим** яйцом: +2 личного тепла, +1 тепла яйцу, прогресс квеста «Оставь комментарий», бейдж `first_comment` (первый раз).

Комментарий под **своим** яйцом:

- Писать **можно** (обсуждение, ответы).
- Тепло, квест и бейдж **не начисляются** (`egg-detail.js`, проверка `user.uid === egg.ownerId`).
