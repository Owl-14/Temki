# Страница яйца (`egg.html`)

## URL

```
egg.html?id={eggId}
```

`eggId` — document id из коллекции `eggs`.

## Кто что видит

| Блок | Наблюдатель | Участник |
|------|-------------|----------|
| Обложка, название, статус | ✅ | ✅ |
| Полное описание | ✅ | ✅ |
| Автор `@username` → профиль | ✅ | ✅ |
| Внешняя ссылка (если есть) | ✅ | ✅ |
| Статистика просмотров | ✅ | ✅ |
| История обновлений | ✅ | ✅ |
| Комментарии (читать) | ✅ | ✅ |
| Комментарий (писать) | ❌ | ✅ |
| Ответить на комментарий | ❌ | ✅ |
| Лайк / дизлайк | ❌ | ✅ |
| +1 к просмотрам | ❌ | ✅ (1 раз, не на своём яйце) |
| Вопрос создателю | ❌ | ✅ (не владелец яйца) |
| Тепло / квесты за просмотр, вопрос, коммент | — | ❌ на своём яйце |
| Редактировать яйцо | ❌ | ❌ (только через профиль → [EDIT.md](EDIT.md)) |

Подробнее про комментарии: [COMMENTS.md](COMMENTS.md).

## Переход с карточки

На главной и в профиле:

- **Название яйца** — ссылка на `egg.html?id=`
- **Обложка** — тоже ведёт на страницу яйца
- Кнопка **«Ссылка»** — внешний URL (Telegram и т.д.)
- **«Редактировать»** — только в своём профиле → `edit-egg.html?id=`

## Ошибки

| Ситуация | Экран |
|----------|-------|
| Нет `?id=` | «Яйцо не найдено» |
| id не существует | «Яйцо не найдено» |
| `published: false` и не владелец | «Яйцо не найдено» |
