# Зал славы (`hall.html`)

Страница лидербордов и витрин: `pages/hall.html`, логика — `assets/js/pages/hall.js`.

В глобальной навигации (`nav.js`) пункт **«Зал славы»** ведёт сюда (раньше был **«Горячие»** → `#hot` на главной).

## Блоки (сверху вниз)

| # | Заголовок | Селектор | Данные | UI |
|---|-----------|----------|--------|-----|
| 1 | Люди | `#hall-users` | `fetchLeaderboardUsers(10)` | Карточки профиля: аватар, имя, `@тег`, тепло, место в топе |

## Карточки людей (`.hall-user-card`)

Рендер: `renderHallUserCard()` в `hall.js`.

- Вся карточка — ссылка на `profile.html?u=`
- Аватар из `users.avatarUrl` или градиент-плейсхолдер
- Если есть `displayName` — имя + `@username` отдельной строкой
- Если нет имени — только `@username` крупно
- Место в рейтинге — `.hall-user-card__rank` (правый верхний угол)

Стили: `style.css` → `.hall-users`, `.hall-user-card*`.

## Тексты UI — `HALL_COPY`

**Важно:** статические русские строки **не хранятся** в `hall.html`. Объект `HALL_COPY` в `hall.js` + `initHallCopy()` выставляет заголовки, подзаголовок, футер и `document.title`.

Причина — см. [RELIABILITY.md](../RELIABILITY.md) § «Кириллица в `hall.html`».

Редактировать тексты зала славы → только `HALL_COPY` в `hall.js`, затем bump `hall.js?v=N` в `hall.html`.

## Связь с главной

На `index.html` блоки **Горячая камера** и **Недавно вылупились** **скрыты** (`hidden`). Разметка и загрузчики в `home.js` сохранены для возможного возврата:

```js
var HOME_FEEDS = { hot: false, hatched: false };
```

Вернуть на главную: `true` в `HOME_FEEDS` + убрать `hidden` с `#hot` / `#hatched` в `index.html`.

На главной видны только **Яйца в инкубаторе** (`#projects`) и **Цыплята** (`#chicks`).
