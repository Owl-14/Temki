# Видение платформы

## Миссия

**Инкубатор** — место, где люди **сносят яйца** (стартапы), **греют** их вместе, **вылупляют**, тестируют продукты и находят **партнёров** для масштабирования.

Не «борд стартапов», а **камера инкубации** с легендой и прогрессом.

## Аудитория

| Роль | Что делает |
|------|------------|
| **Наблюдатель** | Исследует рынок, следит за новинками, находит идеи, которые вдохновляют |
| **Участник** | Помогает проектам стать лучше: тестирует, задаёт острые вопросы, даёт честную обратную связь |
| **Основатель** | Выкладывает идею, фиксирует вехи, вылупляет, отвечает на вопросы |
| **Партнер** | Находит перспективные команды раньше других, выражает поддержку, следит за развитием |

Полные формулировки: [ROLES.md](ROLES.md).

## Жизненный цикл (легенда)

```
яйцо (греется) → вылупление → цыплёнок → курица
```

Статусы в коде: `greetsya` → `tsyplenok` → `kuritsa`.

## Отличие

- Метафора вместо корпоративного языка
- Видимый прогресс (тепло, вехи, ритуалы)
- Q&A отдельно от комментариев
- Тестирование продукта встроено в яйцо
- Масштабирование начинается с **интереса партнёра**, не с денег на платформе
