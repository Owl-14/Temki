# Видение платформы

## Миссия

**Инкубатор** — место, где люди **сносят яйца** (стартапы), **греют** их вместе, **вылупляют**, тестируют продукты и в перспективе находят **кормильцев тепла** (инвесторов).

Не «борд стартапов», а **камера инкубации** с легендой и прогрессом.

## Аудитория

| Роль | Что делает |
|------|------------|
| **Гость** | Смотрит яйца, читает вопросы и комментарии |
| **Участник** | Комментирует, задаёт вопросы, тестирует, копит тепло |
| **Основатель** | Сносит яйцо, ведёт вехи, вылупляет, отвечает на вопросы |
| **Инвестор** (позже) | Оценивает метрики, выражает интерес без обязательства |

## Жизненный цикл (легенда)

```
яйцо (греется) → вылупление → цыплёнок → курица
```

Статусы в коде: `greetsya` → `tsyplenok` → `kuritsa`.

## Отличие

- Метафора вместо корпоративного языка
- Видимый прогресс (тепло, вехи, ритуалы)
- Q&A отдельно от комментариев
- Тестирование продукта встроено в яйцо
- Инвестиции начинаются с **интереса**, не с денег на платформе
