# Инвестиции

## Фазы

| Фаза | Что | Статус |
|------|-----|--------|
| 1 | Интерес без денег | API есть; `investors.html` и вкладка «Тепло» на `egg.html` — заглушки |
| 2 | Донаты «Подкинуть тепла» | план |
| 3 | Верифицированные инвесторы | план |
| 4 | Раунды и доля | план + юристы |

## Фаза 1 — Интерес к теплу

Коллекция `invest_interest/{eggId}_{uid}`:

```js
{ eggId, investorUid, investorUsername, message, status: 'new'|'contacted', createdAt }
```

- Витрина `investors.html` — заглушка «Раздел в разработке»

## Метрики на карточке

- `viewCount`, `heat`
- Количество вопросов / ответов
- Тестеры и средняя оценка
- Вехи, возраст яйца
- Статус (греется / цыплёнок / курица)

## Терминология бренда

- Не «инвестиции» в UI для наблюдателей — **«интерес к теплу»**, роль **«Партнер»**
- Статус `kuritsa` = получил поддержку / вырос

## Юридическое

Перевод денег на платформе потребует Cloud Functions, KYC, оферту — вне текущего MVP.
