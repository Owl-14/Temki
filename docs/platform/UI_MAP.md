# Карта интерфейса

## Навигация

| Пункт | URL | Статус |
|-------|-----|--------|
| Инкубатор | `index.html` | есть |
| Камера | `chamber.html` | реализовано |
| **Зал славы** | `hall.html` | в шапке (`nav.js`); лидерборды + горячая камера + недавно вылупились |
| **Концепция** | `legend.html` | в шапке (раньше «Легенда») |
| Цыплята | `chamber.html?status=tsyplenok` | из dropdown / камеры |
| Курицы | `chamber.html?status=kuritsa` | из dropdown / камеры |
| Инвесторам | `investors.html` | заглушка |
| Уведомления | `notifications.html` | реализовано |

Глобальные ссылки в шапке: **Камера · Зал славы · Концепция** (+ «Яйца» / вход справа).

## Страницы

| Страница | Назначение |
|----------|------------|
| `index.html` | Hero, инкубация, цыплята |
| `egg.html` | Яйцо: описание (+ комментарии), вехи, вопросы, попробовать, инвест-интерес |
| `lay-egg.html` | Создание + анимация прогрева |
| `edit-egg.html` | Редактирование, вехи, вылупление |
| `my-eggs.html` | Кабинет основателя |
| `profile.html` | Публичный профиль, тепло, бейджи |
| `chamber.html` | Каталог с фильтрами |
| `hall.html` | Лидерборды, горячая камера, недавно вылупились |
| `legend.html` | Концепция: стадии проекта, роли участников |
| `investors.html` | Заглушка «Раздел в разработке» |
| `notifications.html` | Уведомления |
| `activity.html` | Лента подписок: «Мои подписки» + обновления яиц |

## Блоки страницы яйца

1. Hero (обложка, статус, автор, метрики)
2. CTA: Ссылка (если указана у яйца)
3. Вкладки: **Описание** (текст, статистика, комментарии внизу) · **Вехи** · **Вопросы** · **Демо** (заглушка «Раздел в разработке») · **Попробовать** (заглушка «Дегустация еще в разработке») · **Тепло** (заглушка «Скоро здесь можно будет инвестировать в яйцо»)
