| Страница | Назначение |
|----------|------------|
| `index.html` | Hero, горячие, лента, недавно вылупились |
| `egg.html` | Яйцо: описание, вехи, вопросы, комментарии, попробовать, инвест-интерес |
| `lay-egg.html` | Создание + анимация прогрева |
| `edit-egg.html` | Редактирование, вехи, вылупление |
| `my-eggs.html` | Кабинет основателя |
| `profile.html` | Публичный профиль, тепло, бейджи |
| `chamber.html` | Каталог с фильтрами |
| `hall.html` | Лидерборды |
| `legend.html` | Онбординг-легенда |
