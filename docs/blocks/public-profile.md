# Блок: публичный профиль

Любой посетитель (включая гостей без аккаунта) может открыть профиль пользователя по `@username`.

---

## URL

```
/profile.html?u=username
```

Пример: https://owl-14.github.io/Temki/profile.html?u=owlkar

---

## Что видно всем (публично)

| Поле | Источник Firestore |
|------|-------------------|
| Аватар | `users/{uid}.avatarUrl` |
| Имя | `users/{uid}.displayName` |
| Юзернейм | `users/{uid}.username` |
| О себе | `users/{uid}.bio` |
| Яйца | `eggs` where `ownerId == uid` and `published == true` |

## Что скрыто от чужих

- Email, пароль, uid (не показываются в UI)
- Кнопки «Снести яйцо» и «Настройки» — **только владельцу**
- Кнопки **«Редактировать»** и **«Удалить»** на карточке — **только владельцу**
- Черновики яиц (`published: false`)
- Редактирование профиля — только `settings.html` для своего аккаунта

---

## Карточки яиц в профиле

| Кто смотрит | Что на карточке |
|-------------|-----------------|
| Гость / чужой | Название → `egg.html`, обложка, описание, «Ссылка» |
| Владелец | То же + **«Редактировать»** и **«Удалить»** |

Логика: `public-profile.js` ставит `editable: true` в `mapFirestoreEgg`, `eggs.js` рендерит кнопку.

Подробнее: [docs/eggs/EDIT.md](../eggs/EDIT.md)

---

## Как попасть на профиль

1. **С карточки яйца** — клик по `@username` под названием
2. **Со страницы яйца** — ссылка на автора
3. **Из меню** — если залогинен: dropdown → «Профиль» (свой)
4. **Прямая ссылка** — `profile.html?u=...`

Гость может открыть любой `@username` по ссылке или с ленты.

---

## Файлы блока

| Файл | Роль |
|------|------|
| `profile.html` | Разметка страницы |
| `js/pages/profile.js` | Точка входа страницы |
| `js/profile/public-profile.js` | Логика публичного просмотра, `editable` на яйцах |
| `js/eggs.js` | Рендер карточек, кнопка «Редактировать» |
| `js/firebase-app.js` | `getUserByUsername`, `fetchUserEggs` |
| `firebase/firestore.rules` | `users` read: all; `eggs` read: published |

---

## Поток данных

```
Клик @username или ?u=
        ↓
getUserByUsername(username)
        ↓
  usernames/{username} → uid
        ↓
  users/{uid} → профиль
        ↓
fetchUserEggs(uid) → только published (через общий запрос, доступен гостям)
        ↓
Рендер header + яйца (editable если свой uid)
        ↓
onAuthStateChanged → если uid совпал → кнопки владельца в шапке
```

---

## Правила безопасности (Firestore)

```js
// users — читать может кто угодно
allow read: if true;

// eggs — гость видит только published
allow read: if resource.data.published == true
  || (request.auth != null && resource.data.ownerId == request.auth.uid);
```

Редактировать чужой профиль или яйца **невозможно** — правила запрещают write без совпадения `uid`.

---

## Состояния UI

| Ситуация | Экран |
|----------|-------|
| Нет `?u=` | «Профиль не найден» |
| Username не существует | «Профиль не найден» |
| Профиль без яиц, смотрит гость | «Тут пока нет яиц» |
| Профиль без яиц, смотрит владелец | «Тут пока пусто — снеси своё» |
| Свой профиль | + «Снести яйцо», «Настройки», «Редактировать» на яйцах |
| Чужой профиль | только публичные данные |

---

## Отличие от settings.html

| | `profile.html` | `settings.html` |
|---|----------------|-------------------|
| Кто открывает | Все | Только владелец |
| Редактирование профиля | Нет | Да |
| Редактирование яиц | Нет (только кнопка → `edit-egg.html`) | Нет |
| URL | `?u=username` | без параметра |
