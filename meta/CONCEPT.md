# Концепция «Инкубатор»

Этот файл — главный источник правды по бренду, текстам и дизайну проекта.
Перед написанием копирайта, добавлением UI или новых секций — сверяйся с ним.

---

## Суть

**Инкубатор** — площадка, где люди собираются, выращивают идеи и запускают свои проекты.
Вся коммуникация строится на метафоре **инкубации яиц**:

**яйцо** → греется → **вылупление** → **цыплёнок** → (с инвестициями) → **курица**

- Стартап в разработке = **яйцо**
- Запуск = **вылупление**
- Запущенный проект = **цыплёнок** (цыплята)
- Стартап с инвестициями (единорог) = **курица** (курицы)

Тон: дружелюбный, чуть ироничный, без корпоративщины. Можно на «ты», можно разговорные слова («щас», «своё»), но не перебарщивать.

## Словарь бренда

| Термин | Значение | Пример |
|--------|----------|--------|
| **Инкубатор** | Сама площадка / сайт / сообщество | «Добро пожаловать в инкубатор» |
| **Яйцо** | Один стартап / проект / темка | «Каждый стартап начинается с яйца» |
| **Яйца** | Несколько проектов | «Смотреть яйца», «Яйца в инкубаторе» |
| **Инкубация** | Процесс развития проекта до запуска | «Всё, что сейчас греется» |
| **Греется** | Проект в разработке, ещё не запущен | «Яйца греются до вылупления» |
| **Вылупление** | Запуск, pop-up, выход проекта в мир | «Греем яйца до вылупления» |
| **Цыплёнок / цыплята** | Вылупившееся яйцо — уже запущенный проект | «Из инкубатора вылупились 3 цыплёнка» |
| **Курица / курицы** | Единорог — стартап, который получил инвестиции | «Cloacc уже курица» |
| **Снести (своё)** | Принести / добавить свою идею, начать свой проект | «Заходи, смотри яйца, и снеси своё» |

### Роли участников

| Роль | Описание |
|------|----------|
| **Наблюдатель** | Исследуй рынок, следи за новинками и находи идеи, которые вдохновляют |
| **Участник** | Помогай проектам стать лучше: тестируй, задавай острые вопросы, давай честную обратную связь. Стань соавтором успеха |
| **Основатель** | Выкладывай идею, фиксируй ключевые вехи развития и превращай проект в глобальный бизнес |
| **Партнер** | Находи перспективные команды раньше остальных. Выражай поддержку, следи за развитием и будь первым, когда проект будет готов к масштабированию |

Подробнее: [docs/platform/ROLES.md](../docs/platform/ROLES.md).

### Жизненный цикл проекта

```
яйцо (греется) → вылупление → цыплёнок → курица (с инвестициями)
```

| Стадия | Статус на сайте | Бейдж |
|--------|-----------------|-------|
| В разработке | греется | `греется` |
| Запущен | вылупился | `цыплёнок` |
| Получил инвестиции | единорог → у нас «курица» | `курица` |

### Склонения «яйцо»

- 1 → **яйцо** (в инкубаторе щас 1 яйцо)
- 2, 3, 4 → **яйца** (2 яйца)
- 5+ → **яиц** (5 яиц)
- 11–19 → **яиц** (11 яиц)

### Склонения «цыплёнок»

- 1 → **цыплёнок**
- 2, 3, 4 → **цыплёнка**
- 5+ → **цыплят**
- 11–19 → **цыплят**

### Склонения «курица»

- 1 → **курица**
- 2, 3, 4 → **курицы**
- 5+ → **кур**
- 11–19 → **кур**

### Чего НЕ использовать

- ~~темка / темки / темщик~~ — устаревшая терминология, заменена на яйца
- ~~проект~~ в пользовательских текстах — лучше «яйцо», «цыплёнок», «курица» (технически в коде можно)
- ~~единорог~~ в пользовательских текстах — у нас это **курица**
- ~~Гость~~ как название роли → **Наблюдатель**
- ~~Кормилец~~ / ~~кормилец тепла~~ → **Партнер**
- Слишком официальный тон: «наша платформа», «инновационные решения»

## Голос бренда

**Да:**
- Короткие, живые фразы
- Метафора инкубации — последовательно, но не в каждом предложении
- «Своё», «снеси», «греется», «вылупляется», «цыплёнок», «курица»
- Ощущение закрытого, но дружелюбного комьюнити

**Нет:**
- Канцелярит и корпоративный язык
- Чрезмерный сленг в каждой строчке
- Путаница метафор: **яйцо = проект**, в счётчике онлайн существительное не используем

## Примеры текстов

- «Добро пожаловать в инкубатор»
- «Яйца в инкубаторе»
- «Всё, что сейчас греется — до вылупления»

### Описания
- «Место, где люди собираются и выращивают яйца — каждый стартап начинается с яйца.»
- «Здесь идеи лежат в инкубаторе, набирают силу и вылупляются в проекты.»
- «Заходи, смотри яйца, и снеси своё.»

### Кнопки
- «Смотреть яйца»
- «Перейти в Telegram» (для конкретного яйца — ок)
- Для запусков: «К вылуплению», «Вылупилось»
- Для запущенных: «Смотреть цыплят», «Уже цыплёнок»
- Для единорогов: «Уже курица», «Наши курицы»

### Счётчик онлайн
- В шапке, в овале вокруг «Инкубатор»: «тут щас **N**» — только число (люди ≠ яйца)

### Футер
- «Инкубатор — греем яйца до вылупления»

## Визуальный стиль

### Направление
**Digital-минимализм** с объёмом: тёмный фон, неоновые акценты, движение, глубина.

### Цвета
- Фон: `#050508` (глубокий тёмный)
- Поверхности: полупрозрачное стекло `rgba(12, 12, 20, 0.78)`
- Акценты: синий `#4facfe`, фиолетовый `#a855f7`, циан `#22d3ee`
- Тепло инкубации: оранжевый `#fb923c`, янтарный `#f59e0b`
- Градиент кнопок: blue → warm (инкубация)
- Текст: `#f4f4f8`, приглушённый `#8b8ba3`

### Шрифты
- Заголовки: **Space Grotesk**
- Основной текст: **Inter**

### Эффекты и анимации
- Плавающая 3D-сетка на фоне
- Тёплое свечение снизу (инкубатор греет)
- Плавающие яйца-контуры на фоне
- Частицы-яйца с линиями тепла (реагируют на курсор)
- Стеклянный липкий навбар с иконкой-яйцом
- Кнопки: подъём, блик, тёплое свечение при hover
- Карточки-яйца: бейдж «греется», полоска тепла, 3D-наклон, zoom картинки
- Плавное появление блоков (fade-up)
- Уважать `prefers-reduced-motion`

### Карточки яиц
- Стеклянный фон, камера-инкубатор вокруг секции
- Силуэт яйца сверху карточки
- Бейдж статуса: `греется` / `цыплёнок` / `курица`
- Анимированная полоска тепла внизу
- Картинка проекта + название + описание + CTA

### Иконография (на будущее)
- Яйцо, тепло, свечение, вылупление — без буквального мультяшного стиля
- Минималистичные, digital, неон
